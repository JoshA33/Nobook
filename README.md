# Nobook

This is JoshA33's unofficial maintenance fork of [ycngmn/Nobook](https://github.com/ycngmn/Nobook).
The 0.1.2 update improves downloads, navigation, script loading and ad detection, with regression tests and CI.
See [maintenance notes and remaining issues](MAINTENANCE.md). Messenger currently works in **Desktop layout**; mobile-layout messaging remains unsupported.

Download this fork from [JoshA33/Nobook releases](https://github.com/JoshA33/Nobook/releases).
Release builds use `com.josha33.nobook` and a dedicated signing key, so they install separately from the official app and the earlier test APK.

## • Setup

1.  **Clone the repository**
    * In Android Studio:
        * File > New > Project from Version Control
        * Paste `https://github.com/JoshA33/Nobook.git` and clone.
    * Or via terminal:
    ```bash
    git clone https://github.com/JoshA33/Nobook.git
    cd Nobook
    ``` 
2.  **Open in Android Studio.** (only if cloned via terminal)
    * Select Open an Existing Project and choose the cloned folder.
3. **Sync the project** to download dependencies.
4. **Run the app** in a device or emulator.
